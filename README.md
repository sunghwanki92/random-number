# 랜덤 번호 생성기

[사이트 열기](https://rannumber-lotto-ki.netlify.app/) · 로그인 없이 사용합니다.

범위·소수 자릿수·개수를 정하고 생성합니다. 결과는 지정 범위 안에서 해당 소수 자릿수로 표시할 수 있는 값입니다. 가능한 값이 없으면 자릿수를 늘리도록 안내합니다. 숫자 중복은 허용합니다. 기준값을 넣으면 최종값 = 기준값 + 생성값입니다.

복권 모드는 오락용입니다. 과거 빈도는 고정 참고자료이며 자동 갱신·당첨 확률 향상을 보장하지 않습니다. 저장 번호는 현재 브라우저에만 남습니다.
